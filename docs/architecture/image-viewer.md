## D. Decode architecture

Metadata comes from a bounded 1 MiB header before pixel allocation. Browser File input supplies a bounded Blob slice; native FileSource supplies authorized 1 MiB ranges. Ordinary raster images use browser color-managed `createImageBitmap` and EXIF orientation. SVG uses sanitized isolated image rendering and remains vector when zoomed. ICO rewrites a temporary single-entry directory around the largest variant; Inspector lists all variants. TIFF renders the first page in a worker and reports additional pages.

WebCodecs handles GIF/WebP/APNG animation when supported. Playback decodes one current frame at a time, closes replaced VideoFrames, honors finite repetitions, pauses on document visibility changes and restores paused frames after file switching. Playback is limited to 4 MP and 1,000 frames. Unsupported animation runtimes display an explicitly labeled first-frame preview. AVIF uses actual runtime codec capability. HEIC/HEIF currently uses capability fallback with dimensions/metadata and a desktop external-open action; no bundled HEVC codec exists. Derived HEIF grids remain metadata-only because tile dimensions cannot safely establish full output allocation.

## E. SVG security

Original SVG never enters application DOM. Parsing rejects malformed XML, DTD/entity declarations, oversized documents and element counts. A conservative tag/attribute/style allowlist removes scripts, event handlers, foreignObject, image/media embedding, external href/URL references, CSS escapes, imports and all use instances (including recursive references). Only local paint-server URLs survive. Sanitized XML is rendered through an isolated blob image. Unsupported SVG constructs can be removed and are reported; this is a static preview, not full SVG application support. Malformed SVG supports escaped Text viewing and return to the default viewer.

## F. Large-image and decompression budgets

Compressed input: 64 MiB; SVG: 4 MiB / 20,000 elements. Normal raster decode: 32 MP. Source dimensions: at most 100,000 on either axis and 1 billion pixels. Unknown dimensions are metadata-only.

Large noninterlaced 8-bit PNGs stream inflate into two scanlines and a maximum 4 MP preview; all five filters, palettes and palette transparency are supported, CRC and decoded byte count are checked. Interlaced/high-bit-depth/color-key-transparent reduced PNGs fail safely with metadata. Workers have a 30-second timeout and are terminated on cancellation. Other large raster formats without a reduced decoder remain metadata-only.

Native large JPEG uses 1/8 DCT scaling before output allocation, a 128 MiB decoder buffer budget, at most 16 MP output, one native job at a time, authorized pinned FileAccess reads and binary PNG IPC. It cannot interrupt a JPEG entropy decode already executing, but late results cannot commit. Reduced JPEG does not apply embedded ICC transforms and explicitly warns. Browser-only large JPEG is safely unavailable.

TIFF is limited to 16 MP, 16-bit unsigned samples, supported photometric layouts and bounded strips/tiles. Directory cycles, tag counts and tag byte allocations are checked before UTIF; recursive metadata pointers are removed in the worker copy. Deflate strips are preflighted against declared decoded pixel bytes before UTIF inflate. Embedded JPEG TIFF, unsupported planar/sample layouts and profile-bearing worker decodes use safe fallback. Associated TIFF alpha is unpremultiplied for canvas rendering.

No OS process peak-memory measurement was performed. Pixel/byte budgets and resource ownership were tested; these do not establish a universal browser/native decoder RSS ceiling.

## G. Interaction and resource lifecycle

Wheel zoom is cursor anchored; pointer drag pans; double click toggles fit/actual. `+`, `-`, `0`, `1`, `R` implement zoom, fit, actual and reset. 100% means one source display pixel per CSS pixel. Fit width, checker/light/dark/tone backgrounds, view rotation, pixel rendering and fullscreen live in More. Minimal controls fade when idle. Zoom/pan/rotation/background/animation state survives file switches.

Image copying rasterizes the current oriented preview to PNG; reduced copies are labeled. Pixel Inspector reports oriented display coordinates, RGBA and HEX/RGB clipboard values, explicitly identifying display sRGB samples. Source profile values are not inferred.

Abort checks surround reads and decode completion. Object URLs, image bitmaps, worker instances, animation decoders and frames register cleanup immediately. Canvas backing stores are cleared on unmount. Browser integration instrumentation observed zero retained bitmaps, URLs, workers, decoders and frames after workspace close.

## H. Metadata

Inspector exposes source/display dimensions, pixel count, orientation, available bit depth/alpha, declared ICC/sRGB profile or Unknown, frame/repetition/page counts, ICO variants, SVG viewBox/element/path/text counts and bounded camera/lens/capture/software metadata. GPS is initially collapsed and is revealed only by expanding Location metadata. Metadata beyond the sampled header may be incomplete; warnings do not invent unavailable values. Pixel coordinates refer to the oriented image.

## J. Actual UI verification and limits

Automated real Edge production-preview UI and actual Tauri WebView2 UI were exercised; these are not human manual tests. The browser report records each fixture and first-visible timing, eight orientation quadrant samples, animation playback/pause/repetitions, paused-frame restoration, SVG Source/fallback navigation, GPS disclosure, zoom/rotation/background, pixel/image clipboard and tab session restoration. No script dialogs, external SVG requests or page errors were recorded. Tauri verified ordinary/transparent/CMYK/oriented images, GIF/WebP, SVG errors, TIFF, AVIF, real HEIC fallback and 100 MP PNG; invoking native decode on an ungranted path returned PERMISSION_DENIED.

Native selected-file dialog → authorized 100 MP JPEG → rendered UI was not automated end to end. The actual native authorized FileAccess/decoder path is covered by Rust tests, and WebView2 separately verifies command authorization. Fullscreen OS behavior, display calibration, animated AVIF, other OS/browser codecs and packaged installer size remain unverified. TIFF page selection, raw sensor decoding, editing/OCR and general Save Copy conversion are outside this implementation.
