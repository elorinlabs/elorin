# Elorin 多语言实现结果

已修改运行时代码，默认跟随系统首选界面语言，支持简体中文、英语、日语、韩语、意大利语、法语和葡萄牙语。在设置 → 语言与地区中可以立即切换，选择会保存，并同步到独立 Focus 窗口。无法匹配支持语言时回退到英语。

## 系统环境接口

- 原生只读命令：`src-tauri/src/user_environment.rs` 中的 `user_environment`。
- 共享接口：`src/platform/user-environment.ts` 中的 `getUserEnvironment(refresh?)`、订阅和 React Hook。
- 返回系统默认语言、首选语言列表、区域语言、设备地区、IANA 时区、UTC 偏移和 Windows 时区标识。
- 地区取自设备设置，不通过网络定位。系统界面语言与区域格式独立处理，避免把地区或区域格式误当成界面语言。

## 翻译和行为

六种非英语语言各包含 1484 个资源键，英语使用源文案并补充原始中文诊断的英语映射；翻译资源的键和参数对应关系经过测试。已接入主窗口、设置、新建文件、查看器、搜索、状态栏、错误恢复提示和 Focus 窗口等实际界面。文件名、用户文件内容、路径、格式标识与诊断代码保持原始值。

现有旧版默认英语设置迁移为跟随系统；明确选择过的语言继续保留。用户在新建文件弹窗中输入的名字不会因语言切换而丢失。搜索限制和错误处理逻辑不依赖翻译后的提示文本。
