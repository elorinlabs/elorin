# Module 13 geometry fixtures

All mesh, drawing, assembly, stress and security fixtures are self-authored synthetic data generated by the scripts in D:/Prism/tests. They contain no customer or proprietary engineering models. Self-authored fixtures may be reused under CC0-1.0.

Two CAD fixtures come from the LGPL-2.1 occt-import-js test repository, with its notice retained in cad/UPSTREAM-LICENSE.txt:
- cad/basic.step: https://github.com/kovacsv/occt-import-js/blob/main/test/testfiles/simple-basic-cube/cube.stp
- cad/basic.iges: https://github.com/kovacsv/occt-import-js/blob/main/test/testfiles/cube-10x10mm/Cube%2010x10.igs

Generate standard fixtures with python tests/generate-module-13.py; generate genuine AP203 faceted STEP assemblies with python tests/generate-module-13-cad.py; generate stress data with python tests/generate-module-13-stress.py.

Assembly contains three 10 mm cubes at x=0,15,30: bounds 40 x 10 x 10 mm. large.step and many-parts.step are equivalent self-authored 1,000-part assemblies, with bounds 475 x 475 x 10 mm.

The texture is a valid self-authored four-color 2x2 PNG. archive.zip includes OBJ + MTL + PNG and glTF + external BIN + PNG. Binary PLY fixtures cover both little and big endian. far-origin.obj contains a 1x1 triangle near coordinates 1e12.

scene/basic.usda is a genuine minimal USDA scene; basic.usdz is a stored ZIP containing it. DAE is a minimal COLLADA XML document. FBX/3DS files are explicitly labeled capability-fallback placeholders, not genuine imported scenes and not evidence of preview support.

Large generated STL/PLY/DXF files are ignored by version control. The 10M STL is approximately 500 MB and is intentionally tested through range-based reduced preview. No large fixture is needed at application runtime.
